========================================
  PRODUCT API - CURL COMMANDS & SPECIFICATIONS
  Base URL: http://localhost:7856/api/products
========================================

category enum values: solar | led | battery | pole

----------------------------------------
1. GET All Products
----------------------------------------
curl -X GET http://localhost:7856/api/products/

Filter by category:
curl -X GET "http://localhost:7856/api/products?category=solar"

----------------------------------------
2. GET Product by ID (Full Solar Technical Datasheet)
----------------------------------------
curl -X GET http://localhost:7856/api/products/<PRODUCT_ID>

3. POST Create Solar Product
----------------------------------------
curl -X POST http://localhost:7856/api/products/ \
  -F "name=100W All-in-One Solar Street Light" \
  -F "category=solar" \
  -F "price=14500" \
  -F "wattage=100W" \
  -F "solarPanelWattage=80W Monocrystalline" \
  -F "voltage=12.8V DC" \
  -F "batteryCapacity=36Ah LiFePO4" \
  -F "backupTime=12-14 Hours" \
  -F "chargingTime=6-8 Hours" \
  -F "efficiency=21.5%" \
  -F "lumes=12000 lm" \
  -F "temperature=6000K" \
  -F "ipRating=IP66" \
  -F "material=Die-Cast Aluminum" \
  -F "dimension=680 x 270 x 85 mm" \
  -F "weight=8.2 kg" \
  -F "guaranteeYear=5 Years" \
  -F "certification=MNRE Approved, BIS, CE, ISO 9001" \
  -F "application=Highway, Rural Roads, Residential" \
  -F "description=Industrial grade solar street light." \
  -F "list[]=High Efficiency Solar Panel" \
  -F "list[]=LiFePO4 Long Life Battery" \
  -F "list[]=Auto Dusk-to-Dawn" \
  -F "img=@/path/to/solar_light.jpg"

----------------------------------------
4. PUT Update Product by ID
----------------------------------------
curl -X PUT http://localhost:7856/api/products/<PRODUCT_ID> \
  -F "price=15200" \
  -F "guaranteeYear=5 Years" \
  -F "backupTime=14-16 Hours"

----------------------------------------
5. DELETE Product by ID
----------------------------------------
curl -X DELETE http://localhost:7856/api/products/<PRODUCT_ID>
